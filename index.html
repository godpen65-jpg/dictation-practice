받아쓰기 연습장

🔊 듣기를 누르면 문제를 읽어 줘요.
펜(원고지)이나 키보드로 쓰고, 정답보기 후 ⭕/✗로 표시해요.
소리가 안 나오면 화면을 한 번 톡 누르고 다시 눌러 주세요.

쓰기 방법

엄마가 만든 받아쓰기 연습장 · 아이와 함께 매일매일 😊

✍️ 받아쓰기 연습장 사용법

앱이 문제를 읽어줘요. 엄마가 옆에서 불러주지 않아도 아이 혼자 할 수 있어요.

1. 무엇부터 고르나요?

  • 낱말 받아쓰기 — 한 낱말씩 또박또박 (99문제 · 33일치)
  • 문장 받아쓰기 — 문장을 듣고 쓰기 (302문제 · 101일치)

고르면 일차 목록이 나와요. 오늘 할 일차를 누르면 그날의 3문제만 나옵니다.

2. 문제 듣기

  • 문제 옆 🔊 듣기를 누르면 앱이 읽어줘요. 여러 번 눌러도 돼요.
  • 너무 빠르면 위쪽 🐢 천천히를 켜 주세요.

3. 쓰는 방법 두 가지

  • ✏️ 펜 — 원고지 칸에 손가락이나 펜으로 직접 써요. 지우려면 지우기.
  • ⌨️ 키보드 — 글자로 입력해요. 이때는 자동으로 채점돼요.

4. 채점하기

  • 다 썼으면 👀 정답보기를 눌러 답을 확인해요.
  • 맞았으면 ⭕ 맞았어요, 틀렸으면 ✗ 틀렸어요를 눌러 주세요.
  • 다 하면 그 일차에 ✅ 표시가 남아요.

5. 진도는 저장돼요

어디까지 했는지 자동으로 저장돼요. 다음에 열면 이어서 하면 됩니다. 아래 ◀ 이전 / 다음 ▶으로 일차를 옮길 수도 있어요.

잘 안 될 때
· 소리가 안 나면 → 화면을 한 번 톡 누른 뒤 🔊를 다시 눌러 주세요. 폰 무음도 풀어 주세요.
· 진도를 저장하려면 → 되도록 같은 기기, 같은 브라우저에서 써 주세요.
· 하루 3문제면 충분해요. 욕심내지 않는 게 오래 가는 비결이에요 😊
